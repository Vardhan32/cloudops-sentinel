      Troubleshooting runbook

      1. Check the health badge: critical means act now, degraded means investigate soon.
      2. Open the incident, note observed value vs threshold and first-seen time.
      3. Acknowledge to claim ownership while diagnosing.
      4. For service incidents, use “Check now” and compare status code / response time history.
      5. Resolve after recovery; the monitor auto-resolves cleared metric conditions.
